# 🎙️ Projeto Transcrever Áudio

Este projeto automatiza a transcrição de arquivos de áudio para texto utilizando Python e a biblioteca Whisper.

## Funcionalidades
* Transcrição de áudios em diversos formatos.
* Interface simples via script Python.

## Tecnologias Utilizadas
* **Python**
* **OpenAI Whisper**
* **FFmpeg** (para processamento de mídia)

## 🛠️ Como executar
1. Clone este repositório.
2. Certifique-se de ter o `ffmpeg` instalado no seu sistema.
3. Execute o comando: `python projeto.py`
